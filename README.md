# Fermín

Calendar-first management for racket sports academies (tennis for now).

```bash
npm install
npm run dev
```

Open http://localhost:3000. The app runs on seeded demo data (200 students,
3 locations); nothing needs configuring yet.

Things to try:

- Press `⌘K` and type `Cambia a Sarah de martes y jueves a lunes y jueves, misma hora`.
- Switch to Malvarrosa and open a class on the rainy day, then "Cancelar por lluvia".
- In "Sin asignar", open a student to see proposed schedules, or assign everyone at once.
- Click a day header for the court-by-court view with every student's name.

Product spec and decisions: `docs/SPEC.md`. Working conventions: `CLAUDE.md`.
